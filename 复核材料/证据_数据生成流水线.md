# 证据 · 数据生成流水线（原报告 → 带出处的问答）

> 回应批改意见：「当前 Notebook 从现成 train.jsonl 读入训练数据，未包含原报告生成带出处问答的程序」。
> 生成程序在 `复核材料/代码/` 与 `scripts/` 两处都有（同一份文件），下面是**四级对应**与复现方式。

## 一、四级对应：原文 → 报告/页码 → 块 → 问答

| 层级 | 字段 | 存在哪 | 样例 |
| --- | --- | --- | --- |
| ① 原始文件 | `doc_file` | `build/docs.json` | `2026-04-29_年报_江苏微导纳米科技股份有限公司2025年年度报告.pdf` |
| ② 页 | `doc` + `page` | `build/pages.jsonl` | `2025年年报` 第 **15** 页 |
| ③ 块 | `id` = `doc-p页码-c块序` | `build/chunks.jsonl` | `2022年年报-p15-c1`（779 字） |
| ④ 问答 | `chunk_id` + `q` + `a` | `build/qa_kept.jsonl` → `build/train.jsonl` | 见下 |

**关键点**：块 ID 本身就编码了出处 —— `2022年年报-p15-c1` 读作「2022年年报 · 第 15 页 · 第 1 块」，
所以任何一条问答都能沿 `chunk_id → 块 → 页码 → PDF` 回查原文。

## 三、每一步的脚本与关键函数

| 步 | 脚本 | 干的事 | 关键实现 |
| --- | --- | --- | --- |
| 1 | `fetch_all_reports.py` | 巨潮资讯按公告类型筛出年报/半年报并下载 PDF | `is_annual()/is_semi()` 正则匹配标题，`download()` 存 `raw/` |
| 2 | `extract_pages.py` | 逐页抽文字，**保留物理页码** | `PdfReader(path).pages` 枚举 → `pages.jsonl`（每行含 `doc/page/text`） |
| 3 | `chunk.py` | 800 字/块、重合 100 字、句末优先；打上 报告/页码/章节 标签 | `split_text()` 先在 60%~100% 区间找「。！？；」断句；`SECTION_RE` 抽「第X节」 |
| 4 | `gen_qa.py` | 每块 3 问，投资者问→董秘答，**答案必须引原文并标出处** | `USER_TMPL` 里写死输出格式；`parse_items()` 解析 JSON |
| 5 | `qc.py` | 三道机器检查：引文是否在原文、数字是否都能在原文找到、页码对不对 | `QUOTE_RE` 抽「」引文；`numbers_in()` 抽数字；`norm()` 去标点比对 |
| 6 | `build_dataset.py` | 每份报告后 20% 的块留作评测（T2），其余进训练；生成换问法 | `by_doc` 按 (页, 块序) 排序后切 20% |
| 7 | `build_eval.py` | 重建四格评测集（T1 = 训练事实的原问法） | 与 `build_dataset` 同一套分块规则，保证可复现 |

## 四、复现命令（4 条）

```bash
python scripts/fetch_all_reports.py     # 1. 下载 7 份财报（PDF 不进仓库）
python scripts/extract_pages.py         # 2. 1329 页 → pages.jsonl
python scripts/chunk.py                 # 3. → 1499 块 chunks.jsonl
python scripts/gen_qa.py                # 4. 70 块 × 3 问 → qa_raw.jsonl（需 .env 里的 DEEPSEEK_API_KEY）
python scripts/qc.py                    # 5. 质检 + 抽检表 qa_qc.csv
python scripts/build_dataset.py         # 6. → train.jsonl / eval.jsonl / kb.jsonl
```

## 五、为什么这条流水线能保证「答案有出处」

1. **切块时就带上页码**（第 3 步），不是事后补；
2. **提示词强制引用**（第 4 步）：`先给结论 → 用「」原样引用片段中的原文 → 最后一行写 依据：[报告 第X页]`；
3. **质检回查**（第 5 步）：把答案里的「」引文和每个数字，逐字回查该块原文，对不上就打低分、低分剔除；
4. **抽检表留痕**（`build/qa_qc.csv`）：210 条逐条记录 引文命中/数字命中/页码是否正确。
