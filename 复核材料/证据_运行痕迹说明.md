| 项 | 值 |
| --- | --- |

## 二、实际生成回答在哪（可直接打开核对）

- `证据_实际生成回答_288条.csv`：288 条，每条都有 **块ID / 出处页码 / 问题 / 参考答案 / 模型实际回答 / 判定**
- `证据_RAG回答_40条.csv`：40 条，同一基座 + BM25 召回，含召回的三块 ID
- 块ID 形如 `2025年年报-p39-c1`，含义是「哪份报告·第几页·第几块」，页码可直接回查 PDF

## 五、诚实说明：训练日志没有单独落盘

`train_lora.ipynb` 里没有写「把 trainer 的 loss 历史存成文件」这一步，所以**本次没有 loss 曲线文件**。
可替代的核对路径有三条：
1. **训练配置与样本量**都能从 notebook 第 3~6 格的代码里读到（模型名、r/alpha、epoch、104 条）；
2. **模型确实被改过**：288 条回答里 82.7%~89.4% 带「」引文与「依据：…第X页」，
   而同一基座不微调时只有 7.5% 会引原文 —— 这是权重被改过的直接痕迹；
3. 如果仍需 loss 曲线，可在 notebook 末尾加一格 `trainer.state.log_history → train_log.csv` 重跑一次（约 25 分钟）。
